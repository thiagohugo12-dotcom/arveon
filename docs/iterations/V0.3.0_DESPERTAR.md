# v0.3.0 — validação incremental

Base remota: b14b641 e 8de85fc. Conexão de progressão corrigida em 1ca1106
(118 verificações). Arquivos da tentativa local anterior reaproveitados após
comparação, preservando curva de XP e atributos já publicados.

Etapa RPG: personagem com pontos, sete receitas únicas, arma/armadura/acessório,
comparação e melhorias +0 a +3. Transações rejeitam toque repetido com receita
antiga. Trocar equipamento não cura. Skills manuais com cooldown e efeitos
procedurais leves: Corte Circular, Investida (colisão), Fúria Ancestral.
Mobile: toque real, swipe dos menus, modais acima dos controles, retrato/paisagem.

Save v5 distingue o v4 publicado (atributos no nível superior) dos novos campos
RPG. Migração é validada antes de mudar o estado. Receitas de 20–40 ouro usam
materiais existentes. Upgrades: 15×(grau+1) ouro, Pedras 2+grau, Essência 1+grau.
Balanceamento provisório para teste humano, sem proficiências ou consumíveis.
