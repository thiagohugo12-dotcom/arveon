# Melee V1 review atlas
RGBA 640x320; 8 poses x 4 directions; 80x80 cells, feet at (40,52).
Rows: front/back/left/right. Rendered by Godot 4.5.1 bake_melee_demos.gd.
Approved torso/head/scarf/backpack and original walking legs reused.
Source-grid hand spans <=12 pixels; same 3x3 hand rasterizer as Bow/Staff.
Axe uses an angular swing; spear uses a straight thrust with perspective.
Approved for main-game integration and fixed TESTE on 14/10/2026.
The atlas remains unchanged and shared with the review scene.
