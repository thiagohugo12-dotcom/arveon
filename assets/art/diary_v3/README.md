# Diário V3 — peças de interface

Acabamento aprovado por Thiago em 12/10/2026 (pedido “pode fazer então”).
Peças autorais produzidas offline por `tools/build_diary_frames.gd`: moldura
de madeira, papel, botão verde, madeira escura e slots ocupados/vazios.
Texturas 96×96 com nove fatias mantêm cantos, relevos e bordas sem esticar.
Papel tem variação discreta preparada na textura, sem shader/runtime generator.
Os ícones gerados em diary_v2 são reutilizados, sem nova geração nem recorte.

Fonte Cormorant Garamond (peso 700), distribuição Google Fonts, sob SIL OFL
1.1, licença em `assets/fonts/OFL.txt`. Arquivo incorporado para consistência
entre Web e desktop; fonte do sistema não é necessária.
Origem: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Somente apresentação. Não acrescenta slots funcionais, equipamentos, poções,
habilidades, capacidade de mochila, alterações de save ou regras de combate.
